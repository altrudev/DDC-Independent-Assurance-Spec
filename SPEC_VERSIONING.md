# Specification versioning

This specification uses semantic versioning once 1.0.0 is reached.

Before 1.0.0:
- MINOR may introduce breaking draft changes.
- PATCH is editorial/non-breaking.
- Every case MUST record the exact spec version used.

Normative text uses MUST, MUST NOT, SHOULD, SHOULD NOT and MAY.
Examples and explanatory notes are informative unless explicitly marked normative.

No implementation may silently reinterpret a case under a later spec version.
